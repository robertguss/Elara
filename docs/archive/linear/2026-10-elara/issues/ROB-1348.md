## Description

Borrowed from Earendil's Pi Durable (background tasks, which an ordinary abort leaves alone). Filed 2026-10-08 from Code Phone's code-level review ([https://cursor.com/agents/bc-468e058c-c9d8-5ac2-9ec5-759523783b0e](<https://cursor.com/agents/bc-468e058c-c9d8-5ac2-9ec5-759523783b0e>)).

Goal: a parent-owned child thread can be marked background. It keeps running when the parent turn is interrupted (Esc), and stops only on an explicit stop of that child or a background-inclusive abort such as `/stop-subtree`. Out of scope: judging and map/reduce, both of which were retired.

Risks: leftover worktrees, and a child with an indeterminate write that the parent no longer watches. The design needs to say how both surface to the owner.

Acceptance: scripted tests show a parent interrupt leaving a background child running, an explicit child stop and a subtree stop ending it, and the indeterminate and leftover-worktree cases surfacing. No real-model run. Deliver a PR for owner merge.

Rough size: M.
