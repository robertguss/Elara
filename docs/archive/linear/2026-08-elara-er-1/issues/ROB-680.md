## Description

## Outcome

Build the thinnest isolated adapter for the comparator pinned by [ROB-772](https://linear.app/robert-guss/issue/ROB-772/fnd-2-preregister-evidence-thresholds-and-comparator-suitability), prove no-fault equivalence for every included operation class, and freeze row-level fault comparability from capability/hook evidence before any external or target fault outcome is exposed. Do not run comparative fault rows here.

## Context

[ROB-772](https://linear.app/robert-guss/issue/ROB-772/fnd-2-preregister-evidence-thresholds-and-comparator-suitability) pins Lemon—or one rule-selected substitute—by immutable commit/configuration and freezes suitability, replacement, eligible classes, and minimum coverage. [ROB-773](https://linear.app/robert-guss/issue/ROB-773/er3-1b-implement-the-neutral-benchmark-runner-and-scorer) supplies the neutral runner/scorer. This issue validates the actual adapter and locks the comparable denominator.

The comparison tests overlapping recovery semantics, not language superiority, model quality, UI, or feature breadth.

## Scope

* Build the minimum out-of-process or isolated test adapter without modifying comparator recovery behavior.
* Run the pinned comparator's documented build/test command and record exact toolchain/configuration.
* Map each frozen applicable task explicitly; account for tool semantic differences.
* Inject deterministic provider/model turns using the pinned runtime's existing supported seam.
* Run no-fault rows only to prove correct final workspace and observation mapping.
* Inventory fault capabilities/hooks without executing confirmatory target/comparator fault outcomes.
* Freeze every row as comparable, not comparable, or adapter failure using [ROB-772](https://linear.app/robert-guss/issue/ROB-772/fnd-2-preregister-evidence-thresholds-and-comparator-suitability) criteria and source-backed reasons.
* Disclose every observation hook and prove it does not add receipt/recovery semantics.
* Calculate whether the frozen external floor can be met: no-fault equivalence for every included operation class plus at least three equivalent fault rows across at least two fault types.

## Non-goals

* Running external or target fault rows.
* Modifying the comparator to add Elara semantics.
* Replacing the comparator after fault-result exposure.
* Changing corpus, eligibility, scores, thresholds, prompts, or target implementation.
* Penalizing unavailable internal seams.

## Acceptance criteria

* Comparator commit, toolchain, build/test command, runtime config, and adapter checksum are immutable and match [ROB-772](https://linear.app/robert-guss/issue/ROB-772/fnd-2-preregister-evidence-thresholds-and-comparator-suitability).
* Every included operation class passes no-fault semantic equivalence before any fault row.
* Every frozen row has a source/capability/hook-backed comparable/not-comparable/adapter-failure classification.
* Fault inclusion is locked from no-fault equivalence and capability evidence, never observed fault outcomes.
* Any observation hook is disclosed and behavior-neutral.
* Floor calculation is explicit. Falling below the floor is valid and forces [ROB-775](https://linear.app/robert-guss/issue/ROB-775/er3-3b-execute-the-frozen-external-runtime-comparison)'s **Insufficient comparability** result rather than row substitution.
* No comparator or target fault result is produced, inspected, or scored.

## Verification

Run adapter/no-fault tests and the pinned runtime's own checks:

```bash
mix test test/elara/benchmark/external_adapter_test.exs --seed 0
mix test test/elara/benchmark/external_no_fault_test.exs --seed 0
mix test
mix format --check-formatted
mix compile --warnings-as-errors
```

Record the comparator command verbatim. The Result must include mapping, comparability, hook, and floor tables plus checksums and proof no fault row ran.
