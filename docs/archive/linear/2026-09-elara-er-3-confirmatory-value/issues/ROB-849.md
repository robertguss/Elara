## Description

## Outcome

After the committed v3 future drand round is available, verify it and deterministically rematerialize every v3 corpus, row, generated value, fixture, external attestation, and dogfood-plan identity under the frozen compatibility predicate.

## Scope

Fetch and cryptographically verify the exact beacon; derive the v3 seed; select only from preregistered compatible candidate/fault assignments; regenerate tasks, rows, generated literals, fixture/workspace digests, adapter-equivalence fixtures, versioned Lemon zero-fault disposition, and dogfood order/checksums; prove byte-identical replay; preserve v1/v2 artifacts.

## Non-goals

No internal/external/dogfood fault execution, target tuning, membership substitution, manual generated-value edits, threshold changes, or post-seed compatibility repair.

## Acceptance criteria

Every selected row passes the pre-seed compatibility predicate and has executable ground truth; all artifacts identify v3/exact beacon; deterministic replay is byte-identical; no-fault ground truth passes; external disposition and dogfood P/I/C are version-aligned; zero relevant v3 fault output exists.

## Verification

Run independent seed replay, compatibility/schema/fixture/manifest/external/dogfood validators, every no-fault acceptance check, full tests, format, warnings-as-errors compile, checksum audit, and clean/pushed Git checks.
