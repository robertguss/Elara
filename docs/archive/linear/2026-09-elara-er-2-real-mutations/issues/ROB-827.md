## Description

## Outcome

Freeze the three operation contracts, shared evidence vocabulary, deterministic failure schedules, safety controls, and GATE-2 decision rules before changing production mutation behavior.

## Contract

For write, patch, and opaque shell, specify digest-bound operation fields; controller/executor/workspace/session facts; causal `completed` versus noncausal `postcondition_satisfied`; structured conflict/indeterminate states; safe next actions; original-owner rules; exact convergence bounds; and every reused ER-1 cut. Include no-fault, same-digest, conflicting-digest, reply-loss, executor-loss, and ledger-loss controls.

Write and patch must declare preimage/postimage semantics. Shell must declare which facts are fundamentally opaque and one typed-adapter seam without parsing command text. Freeze atomic replacement assumptions, symlink/non-file boundaries, process-lifetime observations, fixture membership, seeds/repeats, amendment invalidation, and GATE-2 precedence.

## Acceptance criteria

* Machine-readable manifest and versioned evidence artifact are committed before implementation-result exposure; they are evidence, not a roadmap.
* Every required measure has a named source and is observable; causal completion is never inferred from workspace state.
* Safety/control failure has Stop-first precedence.
* Eligible Universal, Typed-only, and Snapshot-dependent scopes are nonempty and predeclared.
* Existing public tool behavior remains unchanged in this issue.
* Result records commit/blob hashes, audits, deviations, and remaining uncertainty.

## Verification

`mix format --check-formatted`; `mix compile --warnings-as-errors`; static manifest/contract audit; baseline tests for current write/edit/bash behavior. No new real-mutation fault row executes before freeze.
