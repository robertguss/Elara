## Description

## Outcome

Freeze the complete 8–12-task real-repository dogfood manifest and validate its isolation, safety, redaction, failure-control, and report machinery **before any target fault result is exposed**. Do not execute real dogfood tasks here.

## Context

[ROB-679](https://linear.app/robert-guss/issue/ROB-679/er3-2a-prove-baseline-and-receipt-adapter-equivalence) proves baseline/receipt adapter no-fault equivalence. [ROB-772](https://linear.app/robert-guss/issue/ROB-772/fnd-2-preregister-evidence-thresholds-and-comparator-suitability) freezes dogfood thresholds, denominators, exposure/amendment rules, and eligible scope. This issue selects tasks and failure assignments under those rules before [ROB-774](https://linear.app/robert-guss/issue/ROB-774/er3-2b-execute-the-frozen-baseline-versus-receipts-comparison) or [ROB-775](https://linear.app/robert-guss/issue/ROB-775/er3-3b-execute-the-frozen-external-runtime-comparison) may execute a target fault row.

## Scope

* Select and freeze 8–12 genuine bounded tasks using [ROB-772](https://linear.app/robert-guss/issue/ROB-772/fnd-2-preregister-evidence-thresholds-and-comparator-suitability)'s preregistered sampling/exposure rules.
* Include at least: Elixir bug fix, cross-file refactor, test addition, documentation/configuration change, opaque shell/build-dominated task, and workspace conflict.
* Pin every repository/branch commit, expected acceptance command/outcome, provider/model, Elara target/config, and allowed credentials/redactions.
* Freeze task order, at least five supported failure-type assignments, at least two no-fault controls, observation deadlines, stop rules, and exact task/failure denominators/rounding.
* Define isolated disposable worktree/clone creation, cleanliness checks, reset/cleanup, no-push/no-shared-write enforcement, and secret redaction.
* Define report evidence for transcript, receipts/events, Git diff/status, tests, model/tool counts, active time, and planned/unplanned interventions.
* Define evidence required to answer for every injected failure: what ran, what changed, whether it may run again, and what action is safe next.
* Implement and test only plan/report validators and an inert/dummy isolation pilot; do not run a target fault or real dogfood task.
* Freeze conditional behavior: if [ROB-774](https://linear.app/robert-guss/issue/ROB-774/er3-2b-execute-the-frozen-baseline-versus-receipts-comparison) later reports any safety disqualifier, [ROB-776](https://linear.app/robert-guss/issue/ROB-776/er3-4b-execute-the-frozen-dogfood-plan) records **Not executed — internal safety disqualifier** instead of running real tasks.

## Non-goals

* Executing real dogfood tasks or target fault rows.
* Selecting tasks after internal/external fault results.
* Pushing, opening PRs, or changing shared repositories.
* Evaluating provider intelligence or tuning recovery behavior.
* Changing [ROB-772](https://linear.app/robert-guss/issue/ROB-772/fnd-2-preregister-evidence-thresholds-and-comparator-suitability) thresholds/denominators after exposure.

## Acceptance criteria

* Manifest contains 8–12 pinned tasks, at least five failure types, and at least two no-fault controls.
* Exact repository commits, acceptance outcomes, verification commands, task order, failure assignment, deadlines, stop rules, denominators, and rounding are frozen.
* Isolation validator proves dummy work cannot push/write shared state and starts/ends from expected Git state.
* Redaction validator detects seeded credential-like fixtures without printing secrets.
* Report schema captures every required evidence and intervention field and supports both executed and safety-blocked terminal reports.
* Safe-next-action evidence requirements are explicit for 100% of injected failures.
* The 80% no-unplanned-intervention threshold and no-protocol-abandonment rule use fixed denominators.
* No target or comparator fault result and no real dogfood task is produced/inspected.
* Result freezes plan/validator checksums consumed by [ROB-774](https://linear.app/robert-guss/issue/ROB-774/er3-2b-execute-the-frozen-baseline-versus-receipts-comparison), [ROB-775](https://linear.app/robert-guss/issue/ROB-775/er3-3b-execute-the-frozen-external-runtime-comparison), and [ROB-776](https://linear.app/robert-guss/issue/ROB-776/er3-4b-execute-the-frozen-dogfood-plan).

## Verification

Run only plan, isolation, redaction, and report-validator tests:

```bash
mix test test/elara/benchmark/dogfood_plan_test.exs --seed 0
mix test test/elara/benchmark/dogfood_isolation_test.exs --seed 0
mix test test/elara/benchmark/dogfood_report_test.exs --seed 0
mix test
mix format --check-formatted
mix compile --warnings-as-errors
```

The Result must include task/failure table, checksums, dummy pilot evidence, seeded redaction diagnostics, exact tests, and proof no real/fault run occurred.
