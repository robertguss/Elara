## Description

## Outcome

Execute one preregistered deterministic matrix across write, patch, and opaque shell without changing behavior after exposure.

## Matrix axes

Operation class; every relevant ER-1 cut; receipt state; precondition/postcondition/conflict/unavailable observation; same versus replacement owner; same versus conflicting digest. Use deterministic hooks, captured receipts/events, fixed seeds/order, and at least 20 repeats or the frozen deterministic equivalent.

## Acceptance criteria

* Every frozen row has an exact expected classification and safe action.
* No typed mutation duplicates; all digest conflicts reject; accepted ownership never silently fails over.
* Typed rows distinguish causal completion from postcondition satisfaction.
* Opaque rows remain indeterminate without receipt or explicit admissible evidence.
* Result publishes every row, repeated-run count, violations, event references, and candidate gate scope. No implementation change is mixed into execution.

## Verification

Frozen focused matrix, repeated fixed-seed run, full suite, format, and warnings-as-errors compile.
