## Description

## Outcome

At or after the frozen V7 time, fetch and cryptographically verify the exact committed beacon and deterministically materialize a fresh V7 corpus whose every possible candidate path was proven before selection.

## Scope

Require equality from both pinned relays and official-client verification; derive the frozen V7 seed; re-verify the immutable [ROB-873](https://linear.app/robert-guss/issue/ROB-873/er3-v7-fnd-prove-every-candidate-through-the-exact-command-path) semantic report/source hashes before reading the beacon; select only through the frozen rule; emit fresh versioned manifest, row order, literals, fixtures, external attestation, and dogfood plan. Validate selected tasks/rows against the frozen mapping, provider, identity/cardinality, workspace-alias, continuation, causal-terminal, and condition-specific contracts. Preserve V1–V6 byte-for-byte.

No alternate beacon, post-selection constructor/adapter/entrypoint repair, target/timing/comparator/dogfood execution, B/T, threshold/protocol change, V6 retry, or claim.
