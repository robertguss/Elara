## Description

## Outcome

Before committing any V6 beacon, make the frozen corpus materializer capable of deterministically constructing every preregistered candidate—including P02—and mechanically prove every candidate/fault assignment is semantically valid.

## Scope

Create a seed-independent V6 preflight path from the frozen 20-candidate frame and V5 condition-specific contract. Add the missing P02 CRLF exact-edit constructor. Exhaustively instantiate all 20 candidates with deterministic preflight entropy; validate each task's bytes, operation class, steps, initial/environmental/pre-effect/postcondition workspaces, mutation counts, continuation behavior, and condition-specific F1–F4 expectations. Validate both primary and secondary assignments for exactly 40 candidate/fault pairs. Run twice and require byte-identical outputs/hashes. Preserve V1–V5 artifacts byte-for-byte.

## Non-goals

No future beacon/round/time commitment, seed selection, candidate selection/order, V6 manifest, command qualification, target/timing/comparator/dogfood run, B/T, or threshold/protocol change.

## Acceptance criteria

* P02 is a deterministic one-exact-edit CRLF patch task that changes no unrelated byte.
* All 20 candidate constructors execute before any sampling step; IDs exactly equal the frozen frame.
* All 40 primary/secondary assignments pass executable semantic validation, not metadata-only checks.
* Preflight output is canonical and byte-identical across clean reruns; any missing constructor or invalid pair fails closed.
* Prior artifact hash audit passes and zero held-out/result exposure is recorded.

## Verification

Focused preflight/P02/failure tests, two fresh preflight runs and hash comparison, 20/20 and 40/40 independent count/identity audit, prior-version hash audit, JSON validation, `mix format --check-formatted`, `mix compile --warnings-as-errors`, full `mix test`, clean and pushed Git.
