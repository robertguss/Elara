## Outcome

## Precedence

Evaluate **Stop — Stop** first. A safety violation cannot be relabeled Narrow or Pivot.

If Stop does not apply, evaluate Continue—Universal, then Narrow—Typed-only, then Pivot—Snapshot-dependent in that order. The first qualifying outcome wins.

### Stop — Stop

Choose when any is true:

* duplicate external mutation, callback reinvocation without declared atomic ID/digest mutation deduplication, conflicting-digest admission, false success/error, corrupt effect, or silent accepted-job failover occurs; or
* no nonempty typed operation scope satisfies every preregistered truth and liveness row.

Cancel invalidated ER-3 work and preserve all evidence.

### Continue — Universal

Choose only when one operation-independent contract satisfies every preregistered row across write, patch/edit, and opaque shell without command parsing, hidden snapshots, or operation-specific postconditions. The same evidence types, classifications, and permitted actions must apply across all included classes.

### Narrow — Typed-only

Choose only when:

* every safety control passes;
* a nonempty preregistered typed scope satisfies every truth/liveness row;
* durable admission/receipt semantics remain shared;
* automatic reconciliation uses explicit typed preconditions/postconditions; and
* opaque shell remains honestly indeterminate wherever its frozen schedule leaves no durable receipt or explicit adapter evidence.

Select the first passing typed scope in the preregistered precedence; do not choose task-level or post-hoc row subsets.

### Pivot — Snapshot-dependent

Choose only when:

* safety controls pass and no preregistered Universal/Typed-only scope qualifies;
* specific failed rows name an exact snapshot observation that would establish `postcondition_satisfied` or an evidence-backed safe next action; and
* one bounded snapshot experiment can test that observation.

Snapshot evidence must not establish executor `completed` absent exclusive authority or fencing. Keep unchanged ER-3 blocked and create only the smallest named snapshot experiment.
