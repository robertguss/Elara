# Shipping practice workspace

This is a disposable, dependency-free coding exercise, not the Elara runtime.
Keep changes within this workspace. Do not change Elara, contact services,
install dependencies, push commits, or update project tracking.

All money is integer cents. Preserve existing behavior unless the task asks
otherwise. Use `mix test` and `mix format --check-formatted` to verify changes.
Add boundary tests with expected amounts derived from the task specification.
Report commands actually run and their results; do not claim an unrun test passed.
