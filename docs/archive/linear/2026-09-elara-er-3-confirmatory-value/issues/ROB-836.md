## Scope

* Run pinned Lemon's documented build/tests and record toolchain/config.
* Inject deterministic model turns only through Lemon's supported `stream_fn` seam; do not add Elara receipt/recovery semantics.
* Map included write/exact-edit/shell tasks and run no-fault fixtures only.
* Inventory fault capabilities/hooks from source without executing confirmatory fault rows. Freeze each row comparable, not comparable, or adapter failure with source-backed reasons.
* Calculate the frozen floor: no-fault equivalence for every included operation class plus at least three equivalent fault rows across two fault types. [ROB-772](https://linear.app/robert-guss/issue/ROB-772/fnd-2-preregister-evidence-thresholds-and-comparator-suitability) expects zero semantically equivalent rows; confirm rather than force coverage.

## Non-goals

No comparative fault execution, comparator modification, replacement, row substitution, language/BEAM ranking, or target tuning.

## Acceptance criteria

Comparator/config/adapter are immutable; every included class passes no-fault equivalence; every row has a pre-exposure capability-backed classification; hooks are disclosed and behavior-neutral; floor calculation is explicit; below-floor evidence forces **Insufficient comparability** later; no target/Lemon fault result is produced or scored.

## Verification

Run `external_adapter_test.exs` and `external_no_fault_test.exs` under `test/elara/benchmark` with `--seed 0`, pinned Lemon checks, full Elara tests, format, and warnings-as-errors compile.
