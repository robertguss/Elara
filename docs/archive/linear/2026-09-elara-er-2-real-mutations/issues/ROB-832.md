## Description

## Outcome

Select exactly one semantic scope from complete ER-2 evidence: **Continue — Universal**, **Narrow — Typed-only**, **Pivot — Snapshot-dependent**, or **Stop — Stop**.

## Precedence

1. **Stop — Stop:** any duplicate mutation/reinvocation, conflicting-digest admission, false terminal result, corrupt effect, silent failover, or no nonempty typed scope satisfying every truth/liveness row.
2. **Continue — Universal:** one operation-independent contract passes all write, patch, and opaque-shell rows without command parsing, hidden snapshots, or class-specific postconditions.
3. **Narrow — Typed-only:** typed scope passes all rows using explicit pre/postconditions while opaque shell remains honestly indeterminate where evidence is absent.
4. **Pivot — Snapshot-dependent:** no prior scope passes, safety does, and failed rows identify one exact bounded snapshot observation that could establish postcondition/safe action without fabricating completion.

First qualifying outcome wins; product value and BEAM superiority are out of scope.

## Acceptance criteria

* Result starts with exactly one bold decision and audits each branch in order.
* Complete linked write/patch/shell and cross-class tables support the decision.
* Pivot creates only the named bounded experiment; Narrow records exact typed scope; Stop leaves no Todo; Continue creates a separately scoped next evidence project.
* Linear project/status/dependencies match the outcome; no repository roadmap is created.

## Result

**Continue — Universal**

### Precedence audit

1. **Stop — Stop does not qualify.** The complete frozen write, patch, opaque-shell, and cross-class evidence contains no duplicate external mutation, same-ID callback reinvocation, conflicting-digest admission, false terminal result, corrupt effect, or silent accepted-job failover. All 60 frozen rows passed their expected truth/liveness classifications. The shell timeout's test-only 300 ms Sidecar completion-wait override qualifies timing evidence but does not change the digest-bound operation, invocation count, external mutation count, source-qualified state transition, or safe-action rule; it is not a safety or validity failure and therefore is not Stop.
2. **Continue — Universal is the first qualifying branch.** All three operation classes implement one operation-independent, source-qualified rule: admissible causal executor evidence may establish completion; exact declared postimage evidence may refine safe action but cannot manufacture causal completion; absence of admissible evidence remains truthfully indeterminate. Write desired hashes, literal-patch postimage hashes, and shell `files_sha256` are explicit declaration adapters into that rule, not class-specific reconciliation semantics. The shell adapter does not parse command text and the no-adapter shell case remains manual/indeterminate.
3. **Narrow — Typed-only is not reached.** Universal already qualifies. No write+patch-only scope is selected.
4. **Pivot — Snapshot-dependent is not reached.** No failed row identifies a bounded snapshot contradiction, and the passing Universal contract does not depend on hidden snapshots.
5. **Final Stop is not reached.** A nonempty passing scope exists.

### Surviving Universal contract

The selected scope is `write`, literal `patch`, and opaque `shell` under one common protocol:

* stable job ID plus digest-bound admission;
* one logical executor owns accepted work; no replacement-executor failover;
* durable source-qualified receipt/process/workspace observations remain distinct;
* causal `completed`/`failed` evidence remains distinct from noncausal `postcondition_satisfied`;
* exact postimage evidence can prevent an unsafe replay and select a safe next action but cannot prove this job caused the state;
* callback retry after possible external invocation is forbidden without declared atomic job-ID/digest-bound mutation deduplication;
* opaque effects with no declared postcondition remain honestly `:indeterminate`/manual where causal evidence is absent.
