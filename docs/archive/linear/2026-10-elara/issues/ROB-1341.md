Implementation decision with oracle: prepare Mix runtime config/native build in checkout, restore caller cwd before application startup, and let native parser preflight startup rather than duplicating its grammar in Elixir. No release/escript/install updater, dependency bootstrapper, new chat features, grep/glob/retries, visual redesign, or account-backed runs.

Acceptance: offline subprocess checks from another Mix project and non-Mix workspace (including spaces), workspace/list/reopen and scripted prompt/flags, invalid arguments, caller-relative credential/UI paths, cold build confinement, PTY interaction/cleanup, existing compatibility tests and full suite. Mac physical-terminal launcher confirmation remains separate from Linux PTY verification.
