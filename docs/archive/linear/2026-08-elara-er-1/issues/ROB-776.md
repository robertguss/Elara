## Description

## Outcome

Execute the immutable, preregistered dogfood plan on real bounded coding tasks with scheduled failures, or record **Not executed — internal safety disqualifier** when the controlled comparison proves the prototype unsafe. Measure understandable recovery and safe-next-action guidance without changing the plan after fault results.

## Context

[ROB-681](https://linear.app/robert-guss/issue/ROB-681/er3-4-dogfood-real-coding-tasks-with-scheduled-failures) freezes the dogfood manifest, repositories, tasks, failure assignment, isolation validator, and pilot before target fault outcomes are exposed. [ROB-774](https://linear.app/robert-guss/issue/ROB-774/er3-2b-execute-the-frozen-baseline-versus-receipts-comparison) supplies the controlled internal safety/value result. This issue is live execution and reporting only.

## Scope

* Verify dogfood plan, repository commits, Elara commit/config, provider/model, failure assignments, validator, and report schema checksums.
* If [ROB-774](https://linear.app/robert-guss/issue/ROB-774/er3-2b-execute-the-frozen-baseline-versus-receipts-comparison) reports any safety disqualifier, do not expose real tasks to the prototype. Produce the validated terminal result **Not executed — internal safety disqualifier** with linked evidence.
* Otherwise execute all 8–12 frozen tasks in disposable branches/worktrees or cloned fixtures with no pushes or shared-state writes.
* Exercise at least five supported failure types and at least two no-fault controls exactly as assigned.
* Capture transcript, receipts/events, initial/final Git state, diff, test results, tool/model-call counts, elapsed active time, and every planned/unplanned intervention.
* For each injected failure, require evidence-backed answers to: what ran, what changed, whether it may run again, and what action is safe next.
* Preserve every failed, aborted, or indeterminate task; never silently rerun until successful.

## Non-goals

* Changing tasks, acceptance, failure assignments, metrics, or thresholds after [ROB-774](https://linear.app/robert-guss/issue/ROB-774/er3-2b-execute-the-frozen-baseline-versus-receipts-comparison) or external results.
* Pushing, opening PRs, or modifying shared/production repositories.
* Evaluating provider intelligence.
* Fixing recovery semantics during the run.
* Cherry-picking typed-operation successes.

## Acceptance criteria

If execution is allowed:

* All 8–12 planned tasks are reported and at least 8 reach a terminal classified outcome.
* At least five supported failure types and two no-fault controls execute.
* Every run starts from the recorded isolated Git state and ends with diff/status/tests captured.
* Zero duplicate external mutation, callback reinvocation without declared atomic ID/digest mutation deduplication, false success/error, unexplained change, corrupt effect, or unsafe recommendation is required.
* Every injected failure has evidence-backed safe-next-action guidance.
* At least 80% of terminal tasks require no unplanned recovery intervention, using the frozen denominator and rounding.
* No task is abandoned because of protocol friction.
* Qualitative notes remain separate from scored metrics and link to exact run evidence.

If execution is blocked:

* Result begins **Not executed — internal safety disqualifier**, links the exact [ROB-774](https://linear.app/robert-guss/issue/ROB-774/er3-2b-execute-the-frozen-baseline-versus-receipts-comparison) disqualifier, validates that no real dogfood task ran, and supplies no dogfood-value claim.

## Verification

Run the frozen report validator and, only when safety permits, the dogfood plan:

```bash
mix test test/elara/benchmark/dogfood_report_test.exs --seed 0
mix elara.dogfood validate --plan test/fixtures/benchmark/dogfood_plan.json --report <report-path>
mix test
mix format --check-formatted
mix compile --warnings-as-errors
```

Record every task's repository commit, Elara commit, exact verification output summary, report checksum, and redaction check. For a blocked run, validate the non-execution report and clean workspace evidence.
