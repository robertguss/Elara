## Description

## Outcome

Before any V7 beacon commitment, repair the development command path and prove every candidate and frozen assignment through the real Elara adapter, pinned targets, target runner, fault orchestration, recovery, and evidence classifier.

## Scope

Treat V6 as immutable failed evidence: never retry, resume, repair, or reuse it as confirmatory evidence. Generalize the internal mapping to a validated ordered list of plan steps/tool turns plus one final assistant turn. Preserve one-step behavior. Add a plan-aware provider with this exact P06 transition contract:

| Branch | Provider calls | Emitted tools | Remaining state |
| -- | -- | -- | -- |
| no-fault / receipts F2 | 3 | target, continuation | fully consumed |
| baseline F2/F3 or receipts F3 | 2 | target only | continuation explicitly skipped_non_ok; deterministic no-tools halt turn |
| F1/F4 controller recovery | 1 | target only | continuation and final genuinely unconsumed |

Freeze the halt turn shape/text; it is not Task complete. Arm exactly one external barrier/injection bound to the fault-target tool call; continuation may traverse the same native point but is never blocked or faulted. On controller recovery never invent a model-loop continuation.

Identify the fault target uniquely across mapped step, scripted turn, barrier facts, controller intent, and executor ledger. Fail closed on zero/multiple matches. Report both target-only and task-aggregate counts; receipts P06 no-fault/F2 must have exactly two distinct jobs, while halted/recovered P06 fault branches have exactly one. Infer target external mutation count from causal callback attempt × the frozen target-step mutation declaration, not workspace-byte change. Resolve workspace observations through the full row workspace-contract digest alias set; require the expected label to be an admissible alias and never infer causal completion from bytes.

Using deterministic non-beacon development entropy, construct all 20 candidates. Stage A executes every plan under baseline and receipts (40 no-fault eligibility runs). Eligibility is mechanical: both conditions must map and match the frozen no-fault outcome/workspace with complete provider/identity/cardinality evidence. A candidate failing either condition is ineligible for V7 selection and receives no fault run; no adapter-owned semantic shim is permitted. The initial direct development probe identified P03, P05, and W04 as ineligible because their idempotent/conflict semantics are not expressible by the pinned unchanged builtin APIs; the canonical run must reproduce that result rather than repair or conceal it. Stage B executes both primary/secondary assignments for all 17 eligible candidates under both conditions (68 runs), then P06 F3/F4 under both conditions (4 additional continuation probes because F1/F2 are already assigned): 112 total runs. P06-F4 expects fault_target_postcondition under both conditions. Produce only deterministic semantic projections; exclude timing, random job IDs, and held-out literals/results.
