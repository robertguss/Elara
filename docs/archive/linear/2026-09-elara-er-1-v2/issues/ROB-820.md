## Description

## Outcome

Create the versioned ER-1 v2 evidence artifact and wire the existing deterministic matrix to a fresh immutable fixture manifest without executing any v2 matrix row before the freeze commit.

## Contract

Freeze all eight semantic cuts and three controls from v1, changing only the contradictory row-1 count vocabulary:

* controller_intent_count = 0;
* executor_admission_count = 0;
* executor_callback_attempt_count = 0;
* external_mutation_count = 0;
* executor_terminal_result_count = 0;
* session_tool_result_count = 1 with `not_started` and no auto-retry.

Every row must name these six counts, controller/executor truth, historical knowledge, current postcondition, session classification, admissible evidence, action, and ≤1,000 ms bound. Keep row 6 indeterminate exactly as v1.

## Fresh evidence manifest

Commit a machine-readable manifest with:

* contract/schema version;
* all eight rows and three controls;
* a distinct opaque token and operation-argument fixture variant per case;
* fresh-workspace/fresh-controller-DB/fresh-executor-DB policy per case and run;
* frozen seeds `104729`, `130363`, and `155921`;
* the required repeat run and verification commands;
* production baseline commit `a1ee8b39924de38ee08eb0d222d873d3f4061767`.

Wire `test/elara/effect/crash_matrix_test.exs` to read this manifest. The variant must participate in operation arguments/digest; the marker remains non-deduplicating. Do not change production files.

## Invalid Experiment boundary

Freeze that Invalid Experiment applies only to a logically contradictory requirement or required unobservable metric, independently demonstrated. It cannot excuse implementation, safety, truth, liveness, timing, or control failures.

## Acceptance criteria

* New frozen artifact does not edit v1 evidence.
* Row 1 is internally coherent and all count names are source-qualified.
* Manifest has exactly 11 unique case IDs/tokens/variants and the three frozen seeds.
* Matrix consumes the manifest; production diff from the shipped baseline is empty.
* `Elara.Session.Core` is unchanged.
* Before committing, only formatting, static parsing, and production compilation may run; no v2 matrix test executes.
* Result records commit/blob/file hashes, manifest audit, commands, deviations, and uncertainty.
