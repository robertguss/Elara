## Description

Borrowed from Earendil's Pi Durable (unfinished tasks continue from their last checkpoint on restart), filed 2026-10-08 at owner request.

Problem: after a restart, interrupted work needs an explicit follow-up or a resume of the paused queue.

Goal: an opt-in setting on `mix elara.server` that, on restart, continues an interrupted turn automatically only when the interrupted step was a model request or a replay-safe tool (depends on the replay-safe tool declarations issue). Anything indeterminate still stops and waits for the owner. The default stays as today: the original assignment is never automatically resubmitted.

Acceptance: scripted restart tests for model-request resume, replay-safe tool resume, and indeterminate stop; no duplicate messages or tool calls in the session record. No real-model run. PR for owner merge.

Rough size: M.
