The frozen candidate table assigns S01/S02/S03/S04 primary faults F1/F2/F3/F2, while the Universal prose says one shell per F1–F4 and therefore all four shell tasks. Under the amendment rules, do not rewrite S04 or synthesize a shell F4 primary. Apply this deterministic precedence instead:

1. Candidate-table primary/secondary labels remain verbatim, including S04 = F2/F4.
2. Universal's explicit "all four shell tasks" and 12-task total select S01–S04.
3. Select four write and four patch tasks by the frozen one-per-primary F1–F4 seed rule.
4. Every selected task contributes its table-primary row; then the eight lowest-key selected tasks contribute table-secondary rows, yielding exactly 20.

The resulting shell-primary distribution is F1/F2/F3/F2, not balanced F1–F4. This is a disclosed v1 limitation, not a correction or amendment. Membership and row selection remain independent of observed results; no target outcome informs the interpretation. The preregistration artifact stays verbatim.
