## Scope

* Materialize all 12 preregistered historical commit/parent tasks in their frozen order: two no-fault controls and ten injected tasks spanning controller loss, executor loss before/after mutation, completion-result loss, timeout/interrupt, and concurrent conflict.
* Pin repository commits, acceptance commands/outcomes, target/config, scripted/provider plans, allowed credentials, deadlines, stop rules, denominators, and half-away-from-zero rounding.
* Implement disposable clone/worktree isolation, cleanliness/reset/cleanup, no-push/no-shared-write enforcement, and secret redaction.
* Freeze report evidence for transcript, receipts/events, Git state/diff, tests, call counts, active time, interventions, and four safe-action questions for every injected failure.
* Implement validators and an inert dummy isolation pilot only. If later internal execution finds a safety disqualifier, dogfood execution must report non-execution.

## Non-goals

No real dogfood or fault execution; no task selection after fault exposure; no push/PR/shared repository writes; no provider-intelligence evaluation.

## Acceptance criteria

Exactly 12 pinned tasks, ten injected and two controls, cover at least five failure types; acceptance/order/deadlines/denominators are immutable; validators prove isolation/no shared writes and detect seeded credential-like fixtures without printing secrets; report captures every required field and supports safety-blocked terminal output; safe-next-action evidence is required for every injection; no target fault result or real task runs.

## Verification

Run `dogfood_plan_test.exs`, `dogfood_isolation_test.exs`, and `dogfood_report_test.exs` under `test/elara/benchmark` with `--seed 0`, then full tests, format, and warnings-as-errors compile.

## Dependencies

Blocked by internal adapter equivalence. Blocks both immutable internal and Lemon execution so dogfood selection freezes first.
