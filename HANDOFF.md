# Handoff moved to Linear

Read the [current handoff](https://linear.app/robert-guss/document/current-handoff-lab-3-attribution-and-continuation-569eb39fa4cd)
and the selected issue in the
[Elara project](https://linear.app/robert-guss/project/elara-7ee4b27c1215).
Record continuation state, blockers, review evidence, and delivery there. At
each chunk end, the driver replaces this file with a handoff for the fresh
driver and oracle, pointing at Linear for queue, status, and review evidence
rather than restating it.

The complete pre-migration handoff is preserved in the
[import snapshot](https://github.com/robertguss/Elara/blob/03b257159f987e0baf4de9b57f71af156721a5d0/HANDOFF.md).
Its host observations and execution state are historical, not current facts.
