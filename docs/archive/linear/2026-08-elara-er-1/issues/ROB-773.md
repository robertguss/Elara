## Description

## Outcome

Implement and validate the target-neutral ER-3 benchmark runner, scorer, fixture reset, and evidence schema against the frozen corpus. Prove the harness classifies deliberately good and bad runs correctly before any baseline, receipt, or external fault comparison begins.

## Context

[ROB-678](https://linear.app/robert-guss/issue/ROB-678/er3-1-freeze-the-fault-corpus-and-scoring-contract) materializes the preregistered tasks, fault rows, expected invariants, and fixture digests. This issue implements only the neutral execution and scoring substrate. Target-specific adapters and confirmatory runs remain separate review units.

## Scope

* Implement a versioned manifest loader and schema validation.
* Implement deterministic fixture creation/reset and verify initial digests.
* Implement a target-neutral row runner with explicit adapter and fault-hook boundaries.
* Implement machine-readable evidence capture for initial/final workspace, operation observations, classifications, interventions, timing, CPU, storage, and harness failures.
* Implement the frozen primary recovery classification and scorer exactly as preregistered in FND-2.
* Add scorer fixtures for correct completion, duplicate external mutation, callback reinvocation without declared atomic ID/digest mutation deduplication, wrong/corrupt final state, truthful indeterminate, false success, false error, unnecessary replay, manual recovery, and harness failure.
* Add at least two deliberately invalid runs that fail with actionable diagnostics.
* Dry-run every no-fault corpus task through a neutral fixture adapter to prove deterministic reset and expected no-fault workspace outcomes.

## Non-goals

* Implementing baseline, receipt-prototype, or external-runtime adapters.
* Running confirmatory fault comparisons.
* Changing tasks, fault schedules, weights, thresholds, or disqualifiers.
* Using timing sleeps as fault triggers.
* Optimizing target behavior.

## Acceptance criteria

* Runner and scorer consume only versioned frozen inputs and target-neutral adapter responses.
* Fixture reset reproduces the same initial digest for every task across repeated runs.
* Scorer implements the locked paired-row denominator and counts ambiguous/manual union once.
* Safety disqualifiers cannot be offset by completion, speed, or aggregate points.
* Deliberately good and bad fixtures receive the exact expected classifications; at least two invalid fixtures fail for the intended reason.
* Missing, non-comparable, skipped, and harness-failure rows remain distinct.
* Two warmups and 10 measured repetitions are represented without accidentally scoring warmups.
* No target-specific fault result is produced or inspected in this issue.
