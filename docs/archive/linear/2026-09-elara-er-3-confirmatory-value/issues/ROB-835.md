## Description

## Outcome

Build the minimum isolated adapters for pinned baseline Elara and the GATE-2 receipt target, then prove frozen no-fault semantic equivalence before exposing any target fault result.

## Canonical references

* [ROB-772 preregistration](<https://linear.app/robert-guss/issue/ROB-772/fnd-2-preregister-evidence-thresholds-and-comparator-suitability>)

## Scope

* Pin baseline `23e603550253c69846795b13cc2f2670f1122e21` and receipt target `9ff416f2c22327c5ef38edcd52a9e89108fbc726` plus full runtime/configuration.
* Map every applicable frozen task explicitly with isolated workspace/storage and equivalent scripted plans.
* Run no-fault plans only; capture initial/final digests, plan consumption, tool/session observations, and disclosed behavior-neutral hooks.
* Classify each task equivalent, non-equivalent, or adapter failure before fault exposure; freeze adapter/report checksums and the internal paired denominator.
* Preserve the shell-timeout qualification: ER-2 did not prove production enforcement of the unaccelerated 5,000 ms timeout.

## Non-goals

No fault row, B/T calculation, target tuning, frozen-input change, Lemon comparison, or dogfood execution.

## Acceptance criteria

Both immutable targets/configs are recorded; every included task has explicit mapping and isolated state; every included no-fault task reaches the frozen workspace on both targets; evidence is machine-readable; hooks do not add/remove recovery; ineligible tasks are resolved under amendment rules or frozen as ineligible before fault exposure.

## Verification

Run `elara_adapter_test.exs` and `no_fault_equivalence_test.exs` under `test/elara/benchmark` with `--seed 0`, then full tests, format, and warnings-as-errors compile.

## Dependencies

Blocked by the neutral runner/scorer. Blocks dogfood plan freeze and immutable internal execution.

### Hooks and causal evidence

* Baseline exposed no receipt hooks and is recorded as N/A.
* Receipts used only the nine native no-op observation points from intent commit through session-result persistence. The hook only appended point names to an isolated Agent; it did not pause, crash, retry, replace an executor, inject target evidence, or alter recovery.
* Every receipt task recorded one admission, one callback attempt, one terminal record, matching job/digest identity, and `result_persisted: true`. This is no-fault causal evidence only; workspace satisfaction is not treated as proof that a job completed.

### Timeout qualification

The frozen unaccelerated `timeout_ms=5000` is represented by session `tool_timeout_ms=5000`, but neither pinned builtin consumes the plan timeout argument directly. The receipt sidecar also retains its pinned 1,000 ms recovery wait. ER-2 did not prove production enforcement of the exact 5,000 ms argument, and this result makes no timeout claim.

### Exposure, deviations, and limitations

* Exactly one no-fault execution per selected task and pinned target was run. Adapter fault execution is a hard error.
* No fault barrier, B/T score, target tuning, frozen-input change, Lemon comparison, or dogfood execution occurred.
* Deviations: none.
* OS-process/filesystem isolation is an adapter boundary, not a recovery mechanism. No-fault equivalence proves neither fault nor timing equivalence. Opaque shell result bodies are excluded from semantic comparison because commands such as `mix test` may emit nondeterministic metadata; frozen outcome category, transcript shape, exact plan consumption, and workspace digest are compared. The receipt target remains backed by the research-only `Elara.Effect.TestExecutor`.
